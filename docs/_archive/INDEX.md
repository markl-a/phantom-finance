## Conventions

- **Status questions** → `ROADMAP.md`, never the README and never an archived log.
- **Superseded docs** are archived under `docs/_archive/` (moved with `git mv`, a
  tombstone prepended), never deleted.
- The README links here and to `ROADMAP.md` near the top; it does not duplicate
  status or roadmap content.
